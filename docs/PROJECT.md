# Бомбилы — описание проекта (на 25.10.2026)

Telegram Mini App «Бомбилы» — такси и доставка для Енакиево и соседних городов
(Горловка, Донецк, Макеевка, Харцызск). Бот: @bombily_bot.

## Как устроено
- `frontend/index.html` — всё приложение одним файлом (обычный JS).
- `backend/index.js` — сервер на Node: API приложения и бот (getUpdates).
- База — Supabase, проект **wygmuydnodwpbtsdfjuq** (см. `supabase/README.md`).
- Хостинг — Railway: сервис `bombily-app` (сервер) и `bombily-app Copy` (приложение).
  Заливка: push в main → Railway сам обновляет.

## Безопасность (не ломать)
- Любая запись в базу — только через сервер с проверкой подписи Telegram (initData, HMAC-SHA256).
  Публичный ключ в приложении умеет только читать; запись у anon/authenticated отозвана.
- Закрытые таблицы (читает только сервер): contacts, messages, cars, audit_log, promos, broadcasts,
  support_msgs, winback_queue, sources, group_pins, points, inv_links, invitees, call_log, call_sent,
  businesses, biz_staff, biz_orders.
- Триггер guard_privileged_fields не даёт менять защищённые поля пользователя в обход сервера.
- Владелец защищён отдельно (staff_role='owner' и telegram_id).
- В открытую таблицу rides не класть личные данные (телефоны, квартиры).

## Что сделано (кратко)
- Заказы: торг ценой, доставка, межгород, заказ на время, мотоциклы — только доставка.
- Водители: смены, «Настройки смены» (кнопка под «Вы на линии»), карточка в группе со званием,
  лента заказов в закрытой группе водителей.
- Ранги и баллы: Бронза 50 · Серебро 250 · Золото 1000 · Платина 3000 · Алмаз 8000;
  баллы за поездки, час пик, 5★, быстрый отклик, приглашения; штрафы за отказы и жалобы.
  Всё настраивается в панели (Ещё → Ранги и баллы), журнал баллов.
- «Зов на линию»: заявка ждёт дольше 4 минут, свободных нет — бот пишет водителям не на линии.
- Доставка для точек (магазины, аптеки, кафе): заявка → проверка владельцем → режим «Точка»,
  сотрудники по ссылке, телефон получателя только выбранному курьеру, только оплаченный товар,
  заказы магазинов — водителям со звания (по умолчанию от Бронзы).
- Панель: Обзор, Люди, Обращения (водители, жалобы, поддержка, магазины), Статистика, Ещё.
- Права админов по разделам, журнал действий, ежедневная копия базы владельцу, сторож от накруток.

## Решения владельца
- Не делать: имитацию общения ботами в группе; сбор данных из чужих чатов; отдельное APK;
  ВКонтакте; уровни пассажиров и розыгрыш (пока); снятие «мёртвых» водителей (пока).
- Курьер деньги за товар не берёт. Точки — только после проверки. Для точек — бесплатно.
- Магазины пока не искать: сначала набрать водителей и заказы.

## Известные хвосты
- Ночная копия базы берёт не больше 1000 строк из таблицы — нужно выгружать постранично.
- История поездок читается приложением напрямую (адреса видны публичному ключу).
- Старые файлы базы db-01…db-22 не сохранены — устройство базы целиком: `supabase/current-schema.sql`.
