# База «Бомбилы» (Supabase)

Рабочий проект Supabase: **wygmuydnodwpbtsdfjuq**.

## Что здесь лежит
- `schema.sql` — самая первая схема (старая, до всех доработок).
- `migrations/db-23 … db-30` — доработки базы по порядку. Каждая безопасна при повторном запуске.
  Более ранние (db-01 … db-22) были выполнены, но файлов здесь нет.
- `export-schema.sql` — запрос, который выгружает **текущее** устройство базы целиком
  (таблицы, колонки, ограничения, индексы, функции, триггеры, политики, права).
- `current-schema.sql` — результат этого запроса (обновлять время от времени).

## Как сохранить устройство базы
Supabase → SQL Editor → вставить `export-schema.sql` → Run → скопировать ячейку целиком
(или Download → CSV) → сохранить как `current-schema.sql`.

## Как поднять базу заново (если проект Supabase потерян)
1. Создать новый проект Supabase.
2. SQL Editor → выполнить `current-schema.sql` (устройство базы со всеми закрытыми правами).
3. Залить данные из последнего ночного архива, который бот присылает владельцу.
4. Storage: создать хранилище для документов водителей (сами документы удаляются через несколько дней — не критично).
5. В Railway поменять адрес базы и ключи (SUPABASE_URL, ключ service_role) у сервера,
   а в приложении (frontend/index.html) — адрес и публичный ключ.
6. Проверить: бот отвечает, приложение открывается, в панели видны люди.
